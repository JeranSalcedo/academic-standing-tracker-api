# Academic Standing Tracker API

REST API for Academic Standing Tracker, a web-based academic management system that enables students to manage classes, track grades, and organize academic records by semester.

## Features

- Authentication and user management
- Semester management
- Course management
- Subject management
- Class management
- Academic standing tracking
- MySQL database integration

## Technologies Used

- Node.js
- Express
- MySQL
- bcrypt
